# 2차 보완 · 선택 상태와 탐색 일관성

1차 정확성 보완 위에 적용한다. 일정·요금·시간표·항공 참고 항로 레코드는 유지한다.

## 상태 계약

- `selectedVariantByDay`를 날짜별로 관리하고 `routebook-variants-v1`에 저장한다. 날짜 이동·검색·전체 보기로 초기화하지 않는다.
- URL의 명시적 대체안이 저장 선택보다 우선한다. 기본안은 `variant=main`, 우지는 `?day=14&variant=uji`로 정규화한다. 과거 `variant=no-yamazaki` 링크도 호환한다.
- 우지의 원래 데이터/노선 ID `no-yamazaki`와 장소 UID는 변경하지 않는다.
- `variant` 없는 날짜 URL은 그 날짜의 저장 선택을 사용한다. 날짜 없는 처음 진입과 상단 처음으로는 DAY 01로 통일한다.
- 날짜·대체안·일일/전체 보기 전환은 `pushState`, 현재 장소·검색·스크롤 스냅샷은 `replaceState`다. `popstate` 복원은 새 기록을 추가하지 않는다.
- 장소 선택은 `place` URL 매개변수와 스냅샷에 저장한다. 지도 핀/상세, 카드 선택, 검색어/필터, 패널/페이지 스크롤을 복원한다. 오래된 렌더 콜백은 세대 번호로 무시한다.
- 열차 지도 연결도 현재 선택한 대체안에서 같은 날짜/구간을 우선한다. 선택 일정에 없는 구간 때문에 저장 대체안을 임의 변경하지 않는다.

## 검색

각 결과는 `day`, `variant`, `placeId`, `time`, `label`을 가진다. 결과 클릭으로 날짜/대체안 선택 → 장소 카드 스크롤 → 핀과 상세가 열린다. 다른 대체안을 설명하는 요약 문구만으로 기본안을 검색 결과에 잘못 넣지 않는다.

날짜 검색: `1/9`, `01/09`, `1-9`, `1월 9일`, `1월9일`.

## 열차 복원과 시간 상태

- 시간표 조회의 `pickerRequest`와 실제 탑승 선택의 `selectionEpoch`를 분리한다. 패널 열기/닫기·다른 시간표 조회는 복원을 취소하지 않는다.
- 복원 중 상태를 버튼과 패널에 표시한다. 수동 시간표를 보던 중 복원되면 기존 목록은 유지하고 추적 중인 열차로 돌아가는 버튼을 제공한다.
- 새 열차가 실제 선택되거나 추적 종료를 누르면 이전 복원 결과가 이후에 와도 적용하지 않는다.
- 복원 실패/유효하지 않은 자료는 표시하되 저장된 탑승 정보를 임의로 지우지 않는다. 종료는 사용자가 명시적으로 한다.
- 목록 시간 상태는 30초마다 기존 DOM의 문구만 갱신한다. 검색어·선택 열차 강조·초점·스크롤을 유지한다.
- 시각 경과는 `예정 시각 지남 · 실제 위치 확인 필요`로 표시한다. 실제 도착으로 확정하거나 자동 추적 종료하지 않는다.

## 전체 요약

`기본안 기준`과 `현재 선택 기준`을 구분한다. 선택한 대체안의 시내·근교 교통(JPY), 한국 교통(KRW), 관광 장소 카드의 입장·활동 예산 범위를 합산한다. 항공·배·숙소·식음료 및 미확인/변동 항목은 별도로 명시한다. 패스 미적용 비교이며 통화를 임의 환산하지 않는다.

## 검증

```sh
node --test tests/*.test.cjs
```

- `tests/state.html`: 실제 앱 코드로 데스크톱 1180px/모바일 390px 각각 10개 시나리오.
- 날짜별 우지 선택, 전체/일일 왕복, 검색 장소 연결 및 뒤로가기 스크롤 복원, 직접 URL/새로고침, 다섯 날짜 표기, 21→22 뒤로/앞으로, 대체안/보기 모드 history, 처음으로 DAY 01.
- 실제 탑승 저장 후 새로고침하며 시간표 응답을 지연시키고 즉시 패널/다른 시간표를 연다. 원래 열차/운행일/+5분 복원과 새 선택/종료 우선순위를 검사한다.
- 합성 시계를 31초/1시간 진행시켜 목록 DOM·검색·선택 강조·스크롤 보존과 예정 경과 문구를 검사한다.
- `tests/accuracy.html`: 1차 정확성 31개 브라우저 검사 재실행. 두 검증 모두 `state-fixture.html`에서 저장을 격리해 실제 사용자의 기존 열차에 영향을 주지 않는다.
- 저장·합성 시간·응답 지연은 검증 프레임에만 적용한다. 일반 앱에는 검증 분기를 넣지 않는다.

브라우저 저장을 차단하거나 삭제하면 새로고침 간 선택 저장을 보장할 수 없다. 직접 URL로 날짜/대체안/장소를 복원할 수 있다. 실시간 운행 위치·현장 GPS 검증은 이번 회차 범위가 아니다.
