# 3차 보완 · 모바일 조작과 상세 화면

1·2차 정확성 및 선택/URL/history 복원을 유지하며 사용자 조작과 화면 공간을 보완한다. 일정·요금·시간표 레코드·항공 참고 항로는 변경하지 않는다.

| 항목 | 처리 |
|---|---|
| 하단 탑승 카드 | ResizeObserver로 실제 높이를 측정하고 본문/페이지 끝에 높이+여유+safe-area 여백을 확보한다. 모바일과 태블릿/데스크톱 날짜 버튼을 가리지 않는다. |
| 긴 상세 | 1024px 이하에서는 기존 Leaflet popup DOM을 native dialog 하단 패널로 이동한다. 시간표의 기존 갱신/선택 이벤트를 유지한다. 본문은 스크롤, 닫기/일정/지도 이동은 별도 고정 영역이다. |
| 데스크톱 팝업 | 지도 실제 높이·viewport 높이에서 본문 최대 높이를 계산한다. 내용 갱신/펼치기 때마다 지도 경계와 하단 재생 영역을 피하도록 즉시 위치를 맞춘다. |
| 일정 ↔ 지도 | 장소·도보·철도·항공 카드 모두 같은 상세 체계를 쓴다. ‘일정에서 보기’는 해당 카드 선택·스크롤, ‘지도에서 보기’는 상세 닫기 후 지도 이동이다. 지도 다음/이전 장소는 페이지를 목록으로 스크롤하지 않는다. |
| 재생 중 직접 조작 | 클릭/터치/휠/지도 방향키/드래그를 사용자 의도로 감지해 일반/항공 재생을 일시정지한다. 자동 진행은 `source:auto`로 구분한다. 직접 연 상세를 타이머가 덮지 않는다. |
| 전체 보기 | 이전/다음 장소를 숨기고 중앙 버튼을 ‘1일차부터 보기’로 표시한다. 누르면 실제 DAY 01로 이동한다. |
| 컨트롤 공간 | 항공/일반 제어를 배타 표시한다. 모바일 상세 중 막대를 숨기고 하단 패널에 재생 조작을 제공한다. 데스크톱 팝업은 하단 제어 영역을 비운다. 항공 시작 시 해당 지도를 보이게 한다. |
| 터치 | 이전/다음·줌·도시 필터·노선/장소 아이콘·닫기·재생/일시정지의 실제 컨트롤을 최소 44px로 확장한다. 그림 크기는 유지한다. |
| 좁은 화면 기능 접근 | 항상 보이는 ‘지도 설정’에서 야경 강조에 접근한다. 필터·보기·대체안·재생 상태는 aria-pressed로 제공한다. |
| focus/Escape | 패널 처음 열기 때만 opener를 저장한다. 내부로 focus를 이동하고 닫을 때 복귀한다. 중앙 스택이 가장 앞 modal/패널 하나만 Escape로 닫는다. Native modal 안에서는 Tab을 순환한다. |
| 단축키 | 일반 방향키는 Leaflet 이동에 남긴다. 날짜 이동은 브라우저 뒤로가기 조합과도 겹치지 않도록 Alt+Shift+←/→를 사용한다. |

## 화면별 검증

`tests/mobile.html`에서 실제 앱 코드를 320×568, 390×844, 768×1024, 1280×900 프레임으로 실행한다. 각 크기에서 10개 시나리오를 검사한다.

- 22일 전체 + 대체안 3개 렌더링: 총 100개 일정 화면, 가로 넘침 검사.
- 실제 touch box 44px 측정, 필터/보기 상태.
- 야마자키 긴 상세 끝까지 스크롤 후 마지막 ‘장소 길찾기’ hit-test. 하단 패널/팝업 경계 및 일정 복귀.
- 도보/철도/다음 열차/지도 다음 장소 조합. 지도 탐색 시 페이지 스크롤 유지.
- 일반 자동 재생이 자기 팝업으로 멈추지 않는지, 직접 연 상세가 3.5초 후에도 유지되는지, 확대 조작이 일시정지하는지 확인.
- 항공 재생/일반 제어/장소 상세의 표시 우선순위.
- 실제 탑승 선택 후 카드를 유지한 채 1/21 페이지 끝에서 이전/다음 날짜 버튼 hit-test. 모바일은 안전 여백 34px를 추가 재현한다.
- 열차 패널 내부 focus, 도움말 중첩 Escape 한 겹, 원래 버튼 복귀.
- 지도 설정의 야경 토글, 일반 방향키의 실제 지도 이동, Alt+Shift 날짜 이동.
- 전체 보기의 ‘1일차부터 보기’ 실제 이동.

```sh
node --test tests/*.test.cjs
```

1차 `tests/accuracy.html` 31개, 2차 `tests/state.html` 20개 브라우저 회귀 검사도 함께 유지한다. 저장·시계·지연 fixture는 테스트 프레임에만 적용하며 일반 앱에 테스트용 분기를 넣지 않는다.

## 범위와 제한

크기별 검증은 Chrome의 실제 iframe viewport와 DOM hit-test/키보드/재생을 사용한다. 안전 여백 34px는 CSS 입력으로 재현한다. 실제 iPhone Safari/Android 브라우저·화면 회전·키보드·주소창 변화·현지 GPS를 실기기에서 검증한 것은 아니다. VisualViewport 크기 변화와 env(safe-area-inset-bottom)를 반영하도록 구현한다.
