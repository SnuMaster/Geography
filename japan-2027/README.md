# 일본 여행 지도 · 2027

2027년 1월 8일–29일, 22일간의 날짜별 여행 지도.

## 도쿄 지도 · 2026-10-24 개정

기존 `data.json`은 변경하지 않고 도쿄 변경분만 `tokyo-data.json`에서 덧씌웁니다. 도착일의 한국·항공 구간과 다른 지역 일정은 기존 파일에서 읽습니다.

- 1/8–18 도쿄 일정의 보행로와 철도 선형을 `tokyo-routes.json`에 저장해 표시합니다. 선을 누르거나 마우스를 올리면 거리·예상 운임·도보와 환승 순서를 확인할 수 있습니다.
- 장소를 누르면 특징, 계획 체류 시간, 할 일, 비용, 방문 팁과 출처를 표시합니다.
- 1/15는 가와구치코 / 날씨가 나쁠 때 주조장, 1/18은 공연 / 공연 없음으로 전환합니다.
- 도쿄 지하철 72시간권 적용 버튼은 메트로·도에이의 추가 운임을 0엔으로 표시합니다. 패스 구입비 2,000엔은 별도이며 JR·사철·버스·특급은 포함되지 않습니다. 유효시간과 이용 조건을 확인하세요.

거리는 표시된 선의 길이이며 영업거리나 실시간 최적 경로가 아닙니다. 운임은 2026-10-24 확인 자료를 바탕으로 한 성인 1인 편도 계획값입니다. 2027년 실제 운임·운행·입장료는 방문 전 공식 안내를 확인하세요. 버스는 도로와 경유지를 따른 추정 경로, 역내 이동은 대표 연결로 구분합니다. 항공편·공연·식당 예약 완료를 의미하지 않습니다.

1/19 이후 일정과 `assets/travel-plan.pdf`는 기존 10/23판을 유지합니다. 다른 지역의 선은 방문 순서를 나타냅니다.

## 2026-10-24 노선 표시 개선

- 이동선 호버 안내를 지도 안에 고정 폭으로 배치해 좁은 세로 상자로 줄바꿈되던 문제를 해결합니다. 모바일에서도 지도 경계 안에 표시합니다.
- 철도 선·방향 화살표에 노선 색을 적용하고 지도 위, 이동 카드, 상세창, 날짜별 노선 안내에 노선 기호를 표시합니다. 지하철은 원형, JR은 사각형 기호로 구분합니다.
- 스카이라이너는 나리타 스카이액세스/게이세이 본선, 후지회유는 JR/후지급행 구간으로 나눠 색을 표시합니다. 선의 분할은 시각적 구분이며 직통 열차의 환승을 추가하지 않습니다. 기존 거리·운임·일정 데이터는 변경하지 않습니다.
- 글자 기호는 공식 역 번호 안내를 바탕으로 자체 표시하며, 화면 색은 노선 색의 근사값입니다.

노선 표기 참고: [도쿄메트로](https://www.tokyometro.jp/station/index.html), [도에이 지하철 노선도](https://www.kotsu.metro.tokyo.jp/subway/line.pdf), [JR 동일본 역 번호 안내](https://www.jreast.co.jp/press/2016/20160402.pdf), [게이오](https://www.keio.co.jp/global/routes/), [오다큐](https://www.odakyu.jp/station/index.html), [도부 도조선](https://www.tobu.co.jp/railway/guide/line/tojo_line.html), [에노덴](https://www.enoden.co.jp/train/station/), [후지급행](https://www.fujikyu-railway.jp/station/).

## 2026-10-25 1일차 다음 열차·남은 시간

- 1일차에만 `TokyoMetro.Hibiya` 우에노↔이리야와 `JR-East.Takasaki` 지도 구간 우에노↔도쿄의 선·기호·이동 카드를 누르면 화면 안에 다음 3편을 표시합니다. JR은 같은 구간을 운행하는 다카사키·우쓰노미야선 직통 보통/쾌속을 함께 검색하며 조반선·야마노테선·게이힌도호쿠선·특급은 제외합니다. ↔ 버튼으로 반대 방향을 확인합니다.
- 기본 기준은 실제 현재 일본 시각(JST)입니다. 여행 일정의 2027.1.8 시각과 혼동하지 않도록 날짜·시계를 표시합니다. 남은 시간은 1초마다 계산하며 출발 분이 시작되면 다음 열차로 넘어갑니다. 팝업을 닫거나 탭이 숨겨지면 타이머를 멈추고 다시 열면 현재 시각으로 계산합니다.
- **실시간 도착/지연 수신이 아닌 공개 시간표 기준**입니다. JR의 출발역 도착·출발 및 하차역 도착은 각각 원본 필드를 구분합니다. 히비야선 중간역 자료에는 출발 시각만 있으므로 도착 시각으로 바꾸거나 임의 정차시간을 빼지 않습니다. 도착 예정 시각이 지났을 때는 실제 정차 중이라고 단정하지 않고 출발까지를 표시합니다.
- `departure-core.js`: JST·전날 운행분의 00:xx·24:xx·평일/토휴일·내각부 공휴일·연말연시·날짜별 열차 예외를 처리하는 순수 계산 모듈. `day1-timetables.json`은 4방향 1,454개 기본 열차 레코드와 확인된 날짜 예외를 포함합니다. 계산 지원 기간은 자료 개정일 2026.3.14부터 2027.2.28까지이며 이후에는 공식 안내를 표시합니다. 이 기간이 운영사의 운행 보증 기간을 뜻하지 않습니다.

- 상단 **오프라인 저장 → 전체 자료 저장**으로148개 파일 약52.7MiB를 저장합니다. 모든102개 활성 시간표, 22일 전체 일정·경로, 앱 실행 파일과 글꼴, 내장 간략 지도를 포함합니다. 파일별SHA256을 대조하고, 실패·중단은 준비 완료로 표시하지 않습니다. 완료된 패키지라도 캐시 파일이 사라지면 준비 상태를 해제합니다.
- 전체 저장된 시간표는 일반 최근12개 파일 정리에서 보호합니다. 새로고침·처음 여는 지역·열차에서도 오프라인으로 읽을 수 있습니다. 현재의 공개 자료를 저장하는 기능이며 만료된4개 시간표를 유효한 운행 자료로 바꾸지 않습니다.
- 오프라인 배경은 Natural Earth 1:50m 자료를 동아시아 범위로 자른 내장 간략 지도입니다(Public domain). 장소·여행 경로의 상세 좌표는 유지하지만 외부 배경 도로지도·길찾기·운행 정보는 인터넷이 필요합니다. OSM 타일을 일괄 내려받지 않습니다.
- 빌드: 실행파일·JSON을 바꾼 뒤 `python tools/build-offline-manifest.py`. 저장 목록의 바이트수·SHA256은 실제 배포 파일과 같아야 합니다.


## 단순한 지도와 GPS 방향 (2026-10-27)

기본 바탕은 연한 지도이며 일정은 `일정 보기`로 엽니다. 휴대폰·태블릿에서는 하단 창, 데스크톱에서는 오른쪽 목록을 사용합니다. 지도 설정에서 상세한 지도로 되돌릴 수 있습니다.

`내 위치`를 누르면 GPS 점과 정확도 원을 표시합니다. iPhone에서는 위치와 동작·방향 권한을 모두 허용하면 정지 중에도 휴대폰 방향을 파란 부채꼴로 표시합니다. 절대 나침반만 사용하며 임의 기준의 상대 alpha는 사용하지 않습니다. 나침반 미지원/거절 시 속도 0.5m/s 이상이고 방향값이 있는 GPS 진행 방향을 따로 표시합니다. 오래된/부정확한 위치나 방향 자료가 없으면 부채꼴을 숨깁니다. 실제 기기의 나침반 보정·자기 간섭에 따른 오차는 남습니다. 센서와 위치는 메모리에서만 사용하고 추적 종료 시 리스너와 표시를 정리합니다.

오프라인 전체 저장에는 새 지도·방향·일정창 실행 파일도 포함됩니다. 기존 저장본은 온라인에서 다시 저장해야 새 실행 파일까지 준비됩니다.


## 구간별 경로 표시 (2026-10-27)

기본 화면은 현재 선택한 한 이동만 표시하고 앞뒤 버튼으로 이동 순서를 바꿉니다. 출발·도착 장소명만 항상 표시하며 다른 장소 번호는 흐리게 남깁니다. ‘전체 경로’는 일일 화면에서 해당 날짜 전체, 전체 여정에서 모든 22일 경로를 표시합니다. 전체 여정 확대 화면은 해당 지역 날짜의 선택 구간을 보여줍니다. 모든 경로·환승 조각·운임·GPS 매칭 원본은 보존하고 지도 레이어만 구분합니다. 교통 기호는 지도에서 작은 동일 크기이며 회사 로고는 상세에 남습니다. 자동 재생은 지도 설정에서 시작할 수 있습니다.

## 2026-10-27 오프라인 여행 경로 길 안내

- 이동 구간의 **길 안내**로 시작합니다. 보행 경로의 회전·남은 거리·진행률, GPS 위치와 휴대폰/이동 방향을 표시하고 지도 따라가기를 지원합니다. 저장된 OSRM 보행 선형을 기기 안에서 계산하며 네트워크 길찾기 요청을 보내지 않습니다. 작은 출입구 굴곡은 안내에서 줄입니다.
- 철도는 노선·역 방향, 역내 연결과 택시·버스·항공·선박은 저장된 이동 정보를 표시합니다. 검증되지 않은 보행선·개략선·차량·선박 경로로 도보 회전 지시를 만들지 않습니다. 실제 승하차는 현장 안내·탑승 열차 기능과 함께 확인합니다.
- 경로 이탈, 중복 교차점, 위치 도약, 오차가 큰 GPS, 30초 넘게 갱신되지 않은 위치에서는 회전 안내를 보류합니다. 도착 근처에서는 사용자가 도착을 확인해야 다음 구간으로 넘어갑니다. 새 목적지 검색·자동 경로 재탐색은 포함하지 않습니다.
- 출발 전에 **오프라인 저장 → 전체 자료 저장**을 한 번 완료합니다. 전체 일정·경로·계산 코드·시간표·간략 지도가 저장되므로 통신이 끊기거나 오프라인에서 새로고침해도 안내를 다시 시작할 수 있습니다. 상세 배경 지도 대신 저장된 간략 지도와 이동선을 사용합니다. 기기의 GPS 수신·위치 권한이 필요하며 화면이 잠기거나 브라우저가 백그라운드로 가면 위치 갱신은 보장되지 않습니다.
- 이어가기에는 날짜·대체안·구간 번호만 저장합니다. GPS 위치·방향·이동 흔적은 저장하거나 전송하지 않으며 새로고침 후 **길 안내 계속**을 눌러야 추적을 재개합니다.
- 단위 검사: 좌/우회전·출입구 잡음·불량 GPS·이탈·교차·순환·혼합 교통수단·원자료 보존. 브라우저 검사: 4개 화면 크기, 카드/GPS 겹침, 권한 재시도, 통신 차단, 날짜 변경, 위치 추적 수명, 오프라인 새로고침·진행·방향 표시. 실제 기기의 GNSS 수신 성능은 합성 GPS 검사와 별개입니다.

## 2026-10-27 오프라인 도로·역방향 감지·화면 유지

- 오프라인 지도에 여행 경로 주변의 OpenStreetMap 도로·골목·보행로·횡단보도를 추가합니다. 확대 수준에 맞춰 주변 자료만 읽고 그리며, 도로명은 간격을 두고 표시합니다. 저장 범위 밖에서는 범위 안내와 기존 이동선을 표시합니다. ODbL 출처 및 배포 자료는 지도 오른쪽 아래에서 확인합니다.
- 도로 자료는 공개 지역 파일과 이미 확보된 로컬 공개 도로 자료에서 로컬로 추립니다. 사이트와 생성기는 여행 좌표나 실시간 GPS를 외부 도로 조회 API에 보내지 않습니다. 생성기는 네트워크 요청을 하지 않으며, 재생성할 때 공개 지역 PBF 파일을 먼저 준비하고 `tools/build-offline-streets.py --cache LOCAL_PUBLIC_JSON --pbf LOCAL_REGION.osm.pbf`를 사용합니다. PBF 처리에는 pyosmium이 필요합니다.
- 도보 구간에서 실제 이동 방향과 누적 경로 진행이 함께 반대로 이어질 때 경고합니다. 휴대폰 나침반만 돌리거나, 정지 상태의 GPS 흔들림·단발성 위치 변화·오래된 관측으로는 경고하지 않습니다. 정방향 이동이 확인되면 경고를 해제합니다. 차량·선박·철도·개략선에는 도보 역방향 지시를 만들지 않습니다.
- 지원 브라우저에서는 길 안내 시작 시 화면 유지를 요청하고 종료·화면 숨김 시 해제합니다. 화면으로 돌아오면 다시 요청하며, 새 GPS 관측이 오기 전에는 이전 위치로 회전 안내를 재개하지 않습니다. 화면 유지 거절·절전 모드·미지원 상태에서도 길 안내는 계속 사용할 수 있고 버튼으로 재시도하거나 끌 수 있습니다.
- 도로 자료가 오프라인 저장 목록에 포함됩니다. 기존 저장본을 사용 중이면 온라인에서 **전체 자료 저장**을 다시 완료합니다. 실제 기기의 GPS 수신과 운영체제 화면 정책은 모의 GPS·화면 유지 API 검사와 별개입니다.
