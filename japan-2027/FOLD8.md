# 갤럭시 Z 폴드8 일반 모델 화면 최적화

2026-10-30. 아이보리·오렌지 여행 저널을 유지하면서 폴드8의 커버·내부 화면, 회전, 화면 확대, 분할 창과 키보드에 대응합니다. 기존 일정·좌표·시간표·예약 원본은 변경하지 않습니다.

## 기준과 검증 범위

[삼성 공식 설명](https://www.samsungmobilepress.com/articles/making-the-most-of-galaxy-z-fold8)은 일반 폴드8을 커버 5.5인치·10:16, 내부 7.6인치·4:3으로 안내합니다. [공식 사양](https://www.samsung.com/uk/business/smartphones/galaxy-z/galaxy-z-fold8-lavender-256gb-sm-f971blvbeub/)의 해상도는 커버 1972×1248, 내부 1848×2448입니다. 울트라의 화면 비율을 기준으로 만들지 않았습니다.

물리 해상도가 브라우저의 CSS 픽셀과 같지는 않습니다. 416×657과 816×616은 DPR 3을 가정한 대표 검증 크기이며 실제 기기의 기본값이라고 단정하지 않습니다. 화면 확대·브라우저 도구막대·회전·분할 창의 차이를 아래 범위로 함께 검증합니다. 코드에서는 기기명이나 User-Agent를 판별하지 않고 실제 사용 가능한 창 너비를 이용합니다.

| 검증 환경 | CSS 너비×높이 |
| --- | --- |
| 커버·가로 회전 | 416×657, 657×416 |
| 내부·세로 회전 | 816×616, 616×816 |
| 브라우저 도구막대가 차지하는 높이 | 416×580, 816×540, 816×500 |
| 화면 확대·넓은 콘텐츠 설정 | 384×607, 744×562, 1088×821, 640×480 |
| 분할 창 | 360×616 |

## 적용 내용

- 700–1100 CSS px에서는 일정과 지도를 함께 표시합니다. 헤더·도시 소개·날짜 카드를 줄이고 지도 너비 약 70% 이상을 확보합니다. 높이가 줄면 장식보다 스크롤 가능한 일정 목록을 우선합니다.
- 더 좁은 화면에서는 지도를 전체 너비로 쓰고 일정 패널을 열어 봅니다. 세로·가로 화면마다 지도 버튼이 겹치지 않게 배치합니다. 패널을 접고 펼친 사용자 선택은 화면 모드별로 이 페이지에서 기억합니다.
- 이동 카드는 기본적으로 작게 시작합니다. 다음 방문·선택 구간 길 안내·앞뒤 구간은 바로 실행할 수 있고 추가 정보는 펼칩니다. 작은 높이에서는 카드 내부를 스크롤해 접기 버튼이 화면 밖으로 밀려나지 않게 합니다.
- 펼친 내부 화면의 장소 상세는 지도를 함께 볼 수 있는 비모달 카드, 좁은 화면은 모달 시트입니다. 상세가 열린 채 접거나 회전해도 같은 검증된 장소와 URL을 유지합니다.
- 키보드가 열린 상태는 [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)의 보이는 높이·위치와 입력 초점을 이용합니다. 입력창·보내기·접기·요청 중단을 그 범위에 두며 음성 보조 버튼은 잠시 줄입니다. 개인 로그인·메모 입력에도 보이는 공간을 배분합니다. 확대 제스처는 막지 않습니다.
- 접고 펼칠 때 방문 체크·개인 메모·질문 초안·일정/경로 원본을 다시 만들지 않습니다. 화면 변경만으로 AI 요청이나 GPS 권한 요청을 하지 않습니다.
- 배경지도 통신 실패는 보조 도구의 표시와 연결 안내 창에서 확인합니다. 기존 다른 배경·재시도 버튼을 유지하고 길 안내 버튼을 가리지 않습니다. 새로 만든 대화상자를 브라우저가 닫아도 포커스 관리 상태를 해제합니다.
- 오프라인 revision은 `20261030-fold8-1`, 파일 무결성 목록은 171개입니다. `fold-layout.js`와 `fold-layout.css`를 함께 저장합니다. 예전에 저장한 패키지는 다시 저장하세요.

## 자동 검사와 실기기 확인의 구분

`tests/fold-browser.cjs`는 Chromium과 WebKit에서 위 12개 크기의 지도 비율·빈 공간/넘침·44px 버튼과 실제 클릭 대상·일정 스크롤·대체안·방문/메모·장소 상세·날짜 띠를 검사합니다. 접고 펼치는 연속 전환에서는 상세의 모달 변경, 패널 선택, URL·원본·개인 상태·미전송 초안 보존을 확인합니다. 배경지도 실패 시 복구 창과 브라우저에 의한 창 닫기도 검사합니다.

키보드는 레이아웃 뷰포트는 유지하고 보이는 뷰포트만 높이 260px·상단 이동 30px로 줄이는 **모의 환경**입니다. 실제 삼성 키보드를 띄웠다고 보고하지 않습니다. Chrome·삼성 인터넷의 실제 폴드8 화면 확대 설정·주소막대·시스템 글자 크기·OS 키보드와 실제 GPS/방향 센서는 실기기에서 추가 확인할 수 있습니다. WebKit은 호환성 회귀 검사이며 삼성 인터넷 실기기 검사를 뜻하지 않습니다.
