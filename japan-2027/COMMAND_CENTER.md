## 적용 단계

1. 차콜·오렌지 화면, 약 70% 이상 지도 영역, 접는 왼쪽 일정, 필요할 때 여는 오른쪽 상세, 한 줄 메뉴, 기간·현재 KST/JST 표시를 적용합니다. 모바일에서는 브랜드·시각 아래 한 줄 가로 메뉴를 사용합니다.
2. JourneyState·지도·GPS·방향·시간표·예약·내비게이션을 재사용합니다. 날짜·변형·장소 URL과 뒤로/앞으로 이동을 유지합니다. 기존 다섯 일정/경로 JSON은 수정하지 않습니다.
3. 방문 체크를 기존 여행비서 저장소와 공유하고, 순서/시각 조정·비교·승인·5회 되돌리기를 별도 개인 계획으로 저장합니다. 새 연결은 검증된 경로가 없으면 이동시간을 만들지 않습니다. 원본 지도는 기존 경로로 유지합니다. 메모·개인 예약 정보·기기 첨부·백업·알림·PWA를 추가합니다.
4. 인증 Worker에서 ECB 환율과 선택 실행 Open-Meteo 예보를 조회합니다. 실제 철도 지연·플랫폼/출구·새 차량 경로·항공 변경·서버 동기화·잠금 중 푸시는 별도 공급원/구현이 필요합니다.

## 외부 데이터와 오프라인 제약

- [ECB 기준환율](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html): EUR 기준 JPY/KRW를 교차 계산합니다. 은행·카드 환율이 아니며, 조회 실패 시 자동 환산하지 않습니다. 2026-10-30 실제 인증 조회는 기준일 2026-10-29, 1JPY≈8.460664KRW를 반환했습니다. 이 문서의 값은 고정 환율로 사용하지 않습니다.
- [Open-Meteo 문서](https://open-meteo.com/en/docs), [이용 범위](https://open-meteo.com/en/pricing): 개인 비상업 무료 API의 최대 16일 범위와 제한을 따릅니다. 현재 2027년 1월은 범위 밖입니다. 사용자가 조회를 눌렀을 때 공개 목적지만 보내며 정확한 GPS는 쓰지 않습니다.
- [FR24 API FAQ](https://fr24api.flightradar24.com/docs/faq): 실제 항적 추가 조회는 별도 구독/크레딧·편 ID·기록 범위를 검토해야 합니다. 구독이나 유료 API를 새로 구매하지 않았습니다.
- [Apple 웹 푸시](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers), [PWA 백그라운드 제약](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation): 타이머만으로 종료/잠금 중 정확한 알림을 보장할 수 없습니다. Push 구독과 발송 서버를 아직 구성하지 않았습니다.
- 지도는 기존 오프라인 벡터/도로 패키지를 재사용합니다. 제3자 타일을 새로 대량 다운로드하지 않습니다. [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/)과 원래 데이터 라이선스를 유지합니다.
- [일본 기상청 방재](https://www.jma.go.jp/bosai/), [디지털청 입국 안내](https://services.digital.go.jp/en/visit-japan-web/)는 공식 화면 연결이며 자동 상태 수신을 뜻하지 않습니다.

## 개인 보관·복원

첨부는 IndexedDB에 각 2MB 이하, 30개·총 약 20MB까지 저장합니다. 개인 메모·예약 정보·완료 상태는 기존 저장소와 별도 개인 계획 저장소를 사용합니다. 브라우저 자료 삭제·저장 공간 회수 때 없어질 수 있어 백업 파일을 개인 보관해야 합니다. 백업은 본인이 내려받는 파일이며 공개 Git이나 AI 요청에 첨부하지 않습니다. 복원은 검토 버튼을 누른 뒤 기존 개인 저장소를 덮어쓰고 새로고침합니다.

오프라인 shell revision은 `20261030-command-1`입니다. `command-core.js`, `command-center.js`, `command-center.css`, PWA manifest와 아이콘을 포함하여 167개 파일의 해시를 검증합니다. 이전 패키지는 다시 저장해야 합니다. API 요청을 서비스 워커에 캐시하지 않습니다.

## 검증과 남은 현장 확인

Node 회귀 168개가 통과합니다. 새 Chromium·WebKit 검사는 390/900/1440px, 지도 비율, 22일/25안, 방문 저장, 원본 불변 승인/되돌리기, 오른쪽 상세, 경로 필터, 기기 첨부·메모, 자동 API 요청 없음을 다룹니다. 기존 모바일 40개와 통합 52개를 수정 후 다시 통과했습니다. 집 공개를 기대하던 두 검사는 비공개 표시 제한을 검사하도록 바꾸었고, 오른쪽 상세의 실제 패널을 기준으로 스크롤·마지막 링크 클릭 검사를 유지했습니다.

실제 iPhone/Android GPS·방향, 카메라/PDF, 홈 화면 설치, OS 음성, 알림 권한·잠금 동작, Uber 앱 전환은 실기기 확인이 남아 있습니다. 외부 공급원 미연결 기능을 실시간이라고 표시하지 않습니다.
