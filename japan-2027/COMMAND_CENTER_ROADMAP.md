# ROUTEBOOK C · 다크 커맨드 센터 이행 현황

> 적용 브랜치: `feature/japan-2027-command-center-20261029` · 2026-10-29 · 일정 및 경로 원본 JSON 무수정

## 1단계 — 반영됨 (이 PR)

- C 시안에 맞는 다크 네이비·시안·보라 계열 UI. 지도를 기본 중심으로 배치. 기본 상태에서 우측 일정 패널은 숨기고, 열 때만 표시.
- 왼쪽 날짜 패널 접기/펼치기, 모바일 화면 가림막, 22일 선택 드롭다운. 날짜 선택은 기존 `setDay`를 호출하므로 `day`/`variant`/`place` URL·기존 탐색 및 이전/다음 동작 유지.
- 실제 날짜별 방문 항목에 완료 버튼과 진행률 표시. `uid`(없으면 순번)·날짜·일정 변형 기준으로 로컬스토리지에만 저장하며 **예약 완료나 실제 GPS 도착과 혼동하지 않음**.
- 선택 경로에만 네온 강조. 기존 경로, 지도 아이콘, 항공·선박·철도, GPS, 길안내와 예약 다이얼로그는 재사용.
- 새 CSS/JS를 서비스워커의 앱 셸 캐시와 SHA-256 오프라인 준비 목록에 추가. 원본 데이터 파일 5개, 시간표 및 교통 근거 파일은 변경하지 않음.

## 1단계에서 재사용하는 기존 기능 (신규 구현이라고 표기하지 않음)

- 22일 일정, 검색·도시 필터, 시간순 장소 카드 및 이동 상세; 전체 여정 지도로 전환, 선택 구간/전체 경로 보기, 역·이동선 호버; URL 상태 복원.
- 브라우저 허가 후 전경 GPS 관측, 방향 센서 지원 시 방향 표시, 내 위치 따라가기, 현재 구간 중심 도보 안내. 오프라인 지도·GPS 범위는 기존 안내 그대로.
- 항공·페리 참고선, 철도 안내와 예비 운임, 예약 체크리스트, 오프라인 데이터 묶음 및 일정 스냅샷. 이들은 반드시 실제 검증 시각과 개략 선형 안내를 유지.

## 2단계 — 일정 편집과 지도 기능 (미구현)

- 일정 드래그 재배열·변경 전후 비교·되돌리기, 체류 시간과 이동 시간 독립 편집 및 일정별 예산.
- 지도 이동수단별 표시 필터·고배율 상세도 가독성 점검, 전철 환승 출구/승강장 근거 확인, 서비스·노선 출처 최신화.
- 선택일 알림, 방문 데이터 내보내기·가져오기, 사진·메모 개인 저장 및 저장 오류 복구.
- 이동 수단 비교에는 기존 계획값과 공식 당일 자료를 명확히 구분하고, 값이 없으면 '미확인'으로 표시.

## 3단계 — 승인형 AI·실시간 연동 (API 및 서버 필요, 미구현)

- 지각 30분 시 일정 조정 후보 생성, 영업시간·휴식·식사·날씨를 고려한 제안; **확인 후 적용**, 변경 전후 비교, 취소/복원.
- 실제 열차 지연, 항공 변경, 실시간 날씨·재난 경보, 출발·환승·막차 알림은 각 공급처·권한·데이터 이용 계약을 검토해야 함.
- Uber 가격 예상치 API 접근에는 승인이 필요하고, 다른 제공업체와 직접 경쟁 요금 비교는 Uber 이용조건을 확인해야 함. 앱 키를 GitHub Pages의 공개 JS에 넣지 말 것.
- Flightradar24 실시간·과거 위치 API는 이용권과 데이터 보관 정책에 따름. 기존 항로는 참고 선형일 수 있어 2027년 실제 항적처럼 표시하면 안 됨.
- GitHub Pages는 정적 호스팅이라 비공개 API 토큰 저장/서버 프록시가 없음. Cloudflare Workers 등 서버 릴레이와 이용량 제한 필요.

## 4단계 — 오프라인·보안·현장 검증 (부분 구현/검증 필요)

- 기존 서비스워커/IndexedDB/오프라인 도로 경로와 새 UI에 대해 기기·브라우저별 오프라인 실측 수행.
- 일반 OSM 공용 타일 서버의 광범위한 사전 내려받기는 정책 위반이므로, 허가된 오프라인 벡터 타일/자체 호스팅 지도를 사용할 것.
- GPS는 HTTPS와 명시적 사용자 허가가 필요하며 잠금화면·백그라운드 실행은 보장되지 않음.
- **공개 GitHub 저장소에 실주소·좌표를 저장하면 UI에서 숨겨도 보호되지 않음.** 개인정보가 들어 있는 경로 데이터는 공개 배포물에서 제거하거나 비공개 사용자 저장소로 분리하기 전까지 안전하다고 주장하면 안 됨. 현재 원본 데이터 보존 지시 때문에 본 PR은 자료 삭제·좌표 변형을 하지 않음.
- 강우·재난·막차 등의 실시간 정보는 확인 시각, 실패 상태, 출처를 명시해야 하며 GPS 오류·오프라인 시 확인되지 않은 정보를 확정적으로 안내하지 않음.
