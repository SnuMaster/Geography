# 공개 비행 참고 항로

Flightradar24 공개 재생 지도에 표시된 과거 항적을 판독해 만든 참고선이다. 비행기 아이콘은 이 선의 길이를 기준으로 일정한 속도로 움직인다. **원본 GPS 좌표, 실시간 위치, 실제 비행 속도나 고도 자료는 아니다.**

## 공개 출처

| 참고편 | 공항 구간 | 기록일 | 등록기호 | 좌표 수 | 판독한 선의 길이 |
|---|---|---|---|---:|---:|
| [TW251](https://www.flightradar24.com/data/flights/tw251#42477c76) | 대구 TAE → 나리타 NRT | 2026-10-25 | HL8354 | 123 | 약 1,290 km |
| [JL117](https://www.flightradar24.com/data/flights/jl117#4244210e) | 하네다 HND → 이타미 ITM | 2026-10-24 | JA327J | 65 | 약 455 km |
| [NH1189](https://www.flightradar24.com/data/flights/nh1189#4247778b) | 이타미 ITM → 후쿠오카 FUK | 2026-10-25 | JA51AN | 117 | 약 524 km |

JL117은 하네다→이타미 공항 구간의 참고 운항편이다. 참고편 표시는 항공편 예약이나 확정을 뜻하지 않는다. 각 기록은 해당 과거 운항에 대한 것이며 다른 운항의 경로를 보장하지 않는다.

## 지도에서 보기

항공 이동의 선·기호 또는 이동 카드를 열고 **참고 항로 따라가기**를 누른다. 재생 중 비행기의 위치와 방향, 진행률을 볼 수 있으며 일시정지, 계속 재생, 처음부터, 종료 버튼으로 조작한다. 지도에 표시되는 출처에서 참고편의 원문을 열 수 있다.

참고 자료는 이미 불러온 항공 구간의 출발·도착 공항 좌표와 방향이 일치할 때 적용한다. 파일을 불러오거나 검증하지 못하면 기존 개략선이 유지된다.

## 데이터 구성

- `assets/routes/flight-route-sources.json`: 공개 편명·운항일·원문 주소, 지도 보정값, 화면에서 읽은 픽셀 경로, 캡처의 SHA-256 체크섬.
- `flight-route-overrides.json`: 공개 참고편별 지리 좌표, 길이, 출처·정확도 안내. 최상위는 `version`과 `flights`이며, 각 항목은 `id`, `flightNumber`, `referenceDate`, `airportReferenceCoordinates`, `coords`, `distanceM`, `geometrySource`, `geometryNotice`, `flightTrack`을 가진다.
- `../tools/import-flight-reference-tracks.py`: 관측값을 변환하고 결과의 재현성을 검사하는 스크립트. 입력 manifest만 읽고 공개 참고 항로 파일만 생성한다.

## 판독 방법과 한계

전체 화면과 출발·도착 확대 화면에서 식별 가능한 항적을 읽었다. 지도 확대 수준과 월드 픽셀 원점을 이용해 Web Mercator 화면 좌표를 WGS84 위도·경도로 변환한다. 픽셀 선은 허용 오차 1픽셀 이내에서 단순화하며, 확대·전체 화면을 잇는 구간은 기록된 허용 거리 이내인지 검사한다.

원본 지도 스크린샷·타일은 배포하지 않는다. 체크섬과 픽셀 관측값으로 사용한 캡처와 변환 과정을 구별한다. 원본 GPS 파일을 내려받았다는 의미는 아니다.

선에는 화면 해상도에 따른 오차가 있다. 공항 기호에 가린 마지막 접근·지상 구간, 택싱 분기와 순서는 정밀 복원하지 않았다. 끝점이 터미널이나 활주로 끝까지 이어지지 않을 수 있다. 기록된 시각이 없으므로 재생 시간은 시각화용이며 실제 소요 시간으로 해석하지 않는다.

## 생성과 검증

저장소 루트에서 실행한다. Python 표준 라이브러리만 사용하며 네트워크 요청은 하지 않는다.

```sh
python tools/import-flight-reference-tracks.py
python tools/import-flight-reference-tracks.py --check
```

`--check`는 파일을 수정하지 않는다. 허용된 공개 자료 필드, Flightradar24 원문 주소와 편명·기록 ID의 일치, 기록일·수집일 순서, 캡처 보정값, 관측 픽셀 범위, 화면 간 연결 오차, 공항 끝점·방향, 생성된 좌표 파일과의 일치를 검사한다. 검사 결과에는 참고편별 좌표 수·길이·공항 참조점과의 거리가 출력된다.
