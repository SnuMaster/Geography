대상: 2027-01-08~01-29 여행 지도. 기존 일정, 항공 참고 항로, 원본 요금 및 시간표 레코드는 유지한다.

## 자료 유효기간

- `validFrom`: 원본 개정일 또는 명시된 적용 시작일. 날짜가 공개되지 않은 2개 프로필은 `null`이다.
- `validUntil`: 알려진 개정 경계가 있는 4개 아사쿠사선 프로필은 `2026-11-20`. 나머지는 종료일 미공개이므로 `null`이다. 종료일 미공개를 여행일 운행 확정으로 해석하지 않는다.
- `sourceDate`: 기존 원본 메타데이터의 `verifiedSourceDate`를 사용한다. 102개 실제 JSON 파일과 대조한다. 자료 취득일을 임의의 유효 종료일로 사용하지 않는다.
- `calendarFrom`/`calendarThrough`: 날짜 계산 지원 범위다. 자료 유효기간과 함께 제한에 사용하되 공식 운행 보장으로 표시하지 않는다.
- 개별 열차의 유효일·요일·예외일·취소 레코드도 그대로 적용한다.
- 아사쿠사선 [도쿄도 교통국 공지](https://www.kotsu.metro.tokyo.jp/pickup_information/news/subway/2026/sub_p_2026102012843_h.html): 2026-11-21 개정, 역별 시각표 후일 공개. 새 시각표를 임의로 만들지 않는다.

## 실행 가능한 검증

저장소 루트에서:

```sh
node --test tests/*.test.cjs
```

공개 사이트 또는 로컬 미리보기에서 `tests/accuracy.html`을 열고 **데스크톱 + 모바일 검증 실행**을 누른다.

- 공유 순수 계산 검사 17개 + 실제 앱 UI 검사 7개 × 1180px/390px.
- UI: 패스 전환·전체 여정 항공/배 금액, 항공 재생/일시정지/재개/처음부터/종료, 역 확인 후 추가 지연, 팝업 유지 중 JST 자정, 다른 날짜 열차 지도, 아사쿠사 경고/탑승 차단, 합성 GPS 중복선 판별, 22일 일정 전환.
- 자정과 GPS는 격리된 검증 iframe의 합성 입력이다. 검증 문구를 명시하고 실제 위치 권한을 요청하지 않는다. 탑승 저장도 iframe 메모리에 한정한다.
- 실제 휴대전화 GPS·터널·백그라운드 동작과 운영사의 실시간 지연/운휴는 현장 검증 범위 밖이다.
