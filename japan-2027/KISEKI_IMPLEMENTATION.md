## 계정·백그라운드 안내

회원가입은 별도 코드 없이 아이디와 4~128자 비밀번호로 진행합니다. 모든 계정은 기존 서버 전체 AI 비용 상한을 공유합니다. 로그인 세션은 기기에 저장하며 30분 자동 만료는 없습니다. 기존 계정도 계속 로그인할 수 있습니다. 해시·salt만 서버에 저장하며 비밀번호·세션은 로그·Git에 기록하지 않으며 비밀번호는 브라우저에 저장하지 않습니다. 로그인 유지용 세션 토큰만 브라우저 기기 저장소에 저장합니다. 비밀번호 복구·변경과 기기 간 동기화는 미구현입니다. 상단 부제는 같은 위치·폰트의 日本旅行プランナー로 바꾸고 반복 출처 설명과 사진 출처 메뉴를 제거했습니다. 필수 저작권 표기는 정보창의 접힌 저작권·라이선스에 모았습니다.

백그라운드 GPS 길 안내나 종료/잠금 중 푸시를 이번 작업에서 구현했다고 표시하지 않습니다. 서버 Web Push를 추가하면 일정 시각 알림을 보낼 수 있지만 지속적인 위치 기반 회전 안내는 네이티브 위치 서비스 구성이 필요합니다. 현재 알림은 앱 실행 중의 계획 기준입니다. 참고: [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation), [Android 위치](https://developer.android.com/develop/sensors-and-location/location/background).

## 일본 역별 지연 확인 링크

일본 구간의 열차 정보·전체 시간표·탑승 중 화면에 `지연 현황 확인하기`를 추가했습니다. 출발역·도착역과 탑승 열차의 중간 정차역을 한글(일본어) 링크로 표시합니다. 일본어 역명·지역을 사용한 [Google Maps 공식 검색 URL](https://developers.google.com/maps/documentation/urls/get-started#search)로 새 창을 열며 API 키·AI 호출·GPS 전송은 필요하지 않습니다. 한국 KTX에는 표시하지 않습니다.

Google Maps의 정보 제공 여부는 역·노선에 따라 다르며, 이 사이트는 지연 정보를 수신하거나 시간표·예정 도착 시각에 자동 반영하지 않습니다. 기존 공식 시간표·수동 지연 보정·일정·경로 좌표는 유지합니다. 오프라인에서도 메뉴는 남지만 Google Maps에서 자료를 열려면 연결이 필요합니다.

## 날짜별 여행 경비

Expenses를 날짜별 경비 창으로 다시 구성했습니다. 열면 현재 지도 날짜를 기본 선택하며, 이전/다음 또는 22일 선택기로 경비 날짜를 바꿉니다. 경비 날짜 선택은 지도 URL·선택 날짜를 바꾸지 않습니다. 해당 날짜의 선택한 일정안을 기준으로 입력된 예상 비용, 항목별 예상/실제 비교, 기존 지출 내역과 입력 폼을 한 화면에 표시합니다.

22일 전체 탭은 전체 예상·실제·통화별 예산 잔액과 날짜 카드 22개를 표시합니다. 날짜 카드를 누르면 해당 날짜 상세로 이동합니다. 구매한 72시간권은 전체에 한 번만 포함하며 항공·선박 등의 요금은 기존 FareCore 계산으로 합산합니다. 미확인 비용은 별도로 표시하고 원화·엔화는 합산하거나 임의 환산하지 않습니다.

새 expense-ui.js/css는 기존 JourneyState·FareCore·TravelAssistant 개인 저장소를 이용합니다. 기존 지출·예산·방문·준비물의 저장 형식과 원본 일정/경로는 유지합니다. 입력은 경비 창 안에서 처리하며 AI 로그인이나 API 요청을 실행하지 않습니다. 저장 실패는 저장 성공으로 표시하지 않습니다. 오프라인 캐시에 새 모듈을 포함했습니다.

## 간단한 여행비서

AI 여행비서의 기본 화면은 날짜/도시, 다음 목적지·지금 길 안내·오늘 일정·일본어 번역 네 버튼, 대화와 입력창으로 구성합니다. 상단 도구 버튼을 누르면 부가 질문·예약·날짜별 경비·연결/사용량·위치 전송 설정·방문 체크·오프라인 일본어/긴급 도움·준비물·사진 분석·읽어주기를 이용합니다. 기존 개인 저장소와 인증·위치 전송 동의·사진 전송 동의·사용량 상한은 유지합니다.

열 때 입력창을 자동으로 포커스하지 않아 휴대폰 키보드가 즉시 뜨지 않습니다. 번역 방식은 일본어 번역을 고른 동안만 표시하며, 번역 끝내기로 일반 질문으로 돌아갑니다. 음성 미지원 메시지와 음성 제어는 기본 화면에서 숨기고 도구에서 확인합니다. 중단 버튼은 요청 중에만 헤더에 표시하며 채팅과 사진 분석을 중단할 수 있습니다. 설정을 살피거나 날짜를 바꾸는 것만으로 AI 요청을 실행하지 않습니다.

assistant-simple-browser.cjs는 Chromium/WebKit 390/816/1280px에서 기본 네 버튼·도구 분리·자동 키보드 없음·번역 전환·질문 초안/로그인 유지·동의 없는 사진 전송 차단·채팅/사진 요청 중단을 검사합니다. API 응답은 테스트 대체이며 실제 AI나 사용자 사진을 전송하지 않습니다. 기존 22일/25안·계정·음성·키보드/폴드·개인 기록 검사도 유지합니다.

Uber도 선택 구간의 도착지와 일치시키며 항공/선박 구간에서는 숨깁니다.

여행비서의 네 빠른 질문과 채팅 구성을 유지하면서 모델 선택과 사용량 행을 추가했습니다.
