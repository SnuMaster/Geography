## 계정·백그라운드 안내

회원가입은 별도 코드 없이 아이디와 4~128자 비밀번호로 진행합니다. 모든 계정은 기존 서버 전체 AI 비용 상한을 공유합니다. 로그인 세션은 기기에 저장하며 30분 자동 만료는 없습니다. 기존 계정도 계속 로그인할 수 있습니다. 해시·salt만 서버에 저장하며 비밀번호·세션은 로그·Git에 기록하지 않으며 비밀번호는 브라우저에 저장하지 않습니다. 로그인 유지용 세션 토큰만 브라우저 기기 저장소에 저장합니다. 비밀번호 복구·변경과 기기 간 동기화는 미구현입니다. 상단 부제는 같은 위치·폰트의 日本旅行プランナー로 바꾸고 반복 출처 설명과 사진 출처 메뉴를 제거했습니다. 필수 저작권 표기는 정보창의 접힌 저작권·라이선스에 모았습니다.

백그라운드 GPS 길 안내나 종료/잠금 중 푸시를 이번 작업에서 구현했다고 표시하지 않습니다. 서버 Web Push를 추가하면 일정 시각 알림을 보낼 수 있지만 지속적인 위치 기반 회전 안내는 네이티브 위치 서비스 구성이 필요합니다. 현재 알림은 앱 실행 중의 계획 기준입니다. 참고: [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation), [Android 위치](https://developer.android.com/develop/sensors-and-location/location/background).

## 날짜별 여행 경비

Expenses는 날짜별 실제 지출 창입니다. 열면 현재 지도 날짜를 기본 선택하며, 이전/다음 또는 22일 선택기로 경비 날짜를 바꿉니다. 경비 날짜 선택은 지도 URL·선택 날짜를 바꾸지 않습니다. 예상 비용과 비교표를 제거하고 그래프 위 입력 폼과 실제 쓴 돈·기록 수·분류별 가로 막대그래프·기존 지출 내역을 표시합니다. 식비·교통비·입장료·쇼핑·기타에 항공료·숙박비·선박료를 추가했습니다. 22일 전체에서도 연결할 여행 날짜·금액·통화·분류를 골라 입력하며 미리 결제한 비용은 이용할 여행 날짜에 연결합니다. 실제 결제일이나 여러 숙박일로 자동 분할하지 않습니다.
