## 배포 원인과 통합

Cloudflare API로 확인한 프로젝트는 `geography`, 저장소는 `SnuMaster/Geography`입니다. 운영 브랜치는 `main`, 미리보기는 모든 브랜치를 각각 배포합니다. 빌드 명령은 `exit 0`, 루트와 결과 폴더는 저장소 루트(`.`)입니다. 별도 프레임워크 빌드는 없습니다.

PR #14의 `feature/kiseki-visual-refresh-20261030` / `8f4a892db9e76190c1a2a2fa7b7095539e01efca`는 별도 미리보기에만 배포됐습니다. 요청한 `codex-japan-ai-assistant.geography-3tt.pages.dev`는 `codex/japan-ai-assistant`의 `3c58e64b1eda1151d077c2cecd079d909402167a`를 제공하고 있어 해당 주소에서는 바뀌지 않았습니다. PR #14의 문장 로고·CSS·브랜드·PWA 선언을 재사용하고 기존 AI 브랜치에 통합합니다. `main`은 변경하지 않습니다.

원본 일정·시간·좌표·요금 JSON은 수정하지 않습니다. 기존 저장 키, 장소 UID, 대체안 ID, 예약 저장소, IndexedDB 첨부와 백업 형식을 유지합니다. 새 설정은 `kiseki-map-theme`, `kiseki-layout-v1`에만 저장합니다. 기존 백업 파일도 계속 읽습니다. 새 계정으로 로그인해도 다른 기기에 개인 자료를 자동 전송하거나 동기화하지 않습니다.

## 브랜드·지도·사진

PR #14의 금색 원형 테두리, 후지산·붉은 태양·벚꽃 문장을 재사용합니다. 브라우저 제목, favicon, Apple touch icon, PWA SVG/192·512 PNG를 통일했습니다. 로고 PNG는 같은 SVG에서 렌더링했습니다.

아이보리 헤더와 사이드바, 네이비 글자, 오렌지 선택 표시를 사용합니다. 지도 다크 모드는 배경 타일/오프라인 바탕만 변환하며 실제 경로의 노선색과 좌표를 변경하지 않습니다. 기존 상세/간략 지도 선택과 야간 일정 기능은 별도로 유지합니다.

사진 원본·저작자·CC BY/CC BY-SA/CC0 조건은 `assets/photos/sources.json`과 More → 사진 출처에 있습니다. Commons 축소본을 로컬 저장하고 화면에 맞게 잘라 표시합니다. 자료의 촬영 시기·계절과 여행일은 다르며 날씨 근거가 아닙니다.

## 계정·백그라운드 안내

회원가입은 기존 개인 코드가 있는 소유자만 한 번 만들 수 있습니다. 계정 인증은 기존 AI 비용 상한과 30분 메모리 세션을 공유합니다. 해시·salt만 서버에 저장하며 비밀번호/개인 코드는 로그·Git·브라우저 저장소에 기록하지 않습니다. 본인의 실제 계정 생성과 비밀번호 입력은 사용자가 직접 합니다.

백그라운드 GPS 길 안내나 종료/잠금 중 푸시를 이번 작업에서 구현했다고 표시하지 않습니다. 서버 Web Push를 추가하면 일정 시각 알림을 보낼 수 있지만 지속적인 위치 기반 회전 안내는 네이티브 위치 서비스 구성이 필요합니다. 현재 알림은 앱 실행 중의 계획 기준입니다. 참고: [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation), [Android 위치](https://developer.android.com/develop/sensors-and-location/location/background).

WebKit은 `ASSISTANT_BROWSER=webkit`로 동일한 새 검사들을 실행합니다. KISEKI 검사는 1440/390/416/816px에서 22일/25안과 사진·필터·지도 3모드·다크/상세·계획/실제 지출·자료 출처·방문 상태·원본 불변·재시작을 다룹니다. 1/4/11/12/22일을 포함합니다. 폴드 검사는 별도 12개 크기와 모의 VisualViewport 키보드·연속 회전·상세창·지도 통신 실패를 다룹니다.

자동 GPS/키보드 검사는 모의 환경입니다. 실제 휴대폰 센서, 실제 OS 키보드·알림 권한·잠금, 설치, Uber 앱 전환, 현장 운임·교통 변동을 확인했다고 주장하지 않습니다. 외부 데이터 불가 상태를 구분하는 것이 이번 기능의 정상 동작이며 가짜 실시간 자료를 추가하지 않습니다. 최종 CI 링크와 배포 커밋은 PR 및 작업 결과 보고서에 기록합니다.
